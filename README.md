## 搬瓦工三网优化指的是什么线路？

三网优化就是回程分流：电信方向走 CN2 GIA（AS4809），这是电信国际线路里的最高档；移动方向走 CMIN2，移动自家的高端国际链路；联通方向标称走 CUP，即 9929 精品网。作为对比，普通 163 骨干在晚高峰的丢包率可以飙到 30% 左右，而公开测评数据里 CN2 GIA 洛杉矶节点的平均延迟约 158ms、峰值时段丢包接近零——这就是三网优化款晚高峰还能稳定跑满速的原因。

还有一个容易忽略的点。搬瓦工在 2025 年给五个机房挂上了"CN2GIA-E + CMIN2 + CUP"的三网标注，但搬瓦工中文社区的整理指出，标注里的联通 CUP 方向，实际接入的仍是电信 CN2 GIA。对联通用户来说这不算坏事，CN2 GIA 本身质量过硬，只是你要清楚流量的实际走向，别把“标了 CUP”直接理解成“一定走 9929"。
